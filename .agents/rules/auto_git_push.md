# Aturan Otomatis Git Push

Setiap kali selesai melakukan modifikasi, penambahan, penghapusan, atau perbaikan pada script/kode program:
1. Pastikan kode sudah teruji dan valid.
2. Lakukan `git add .`.
3. Lakukan `git commit -m "..."`.
4. Lakukan `git push origin main`.
5. Laporkan status push kepada pengguna.
